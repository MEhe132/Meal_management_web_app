# Git Cheat Sheet (গিট চিটশিট) 🚀

লোকাল রিপোজিটরি তৈরি (git init) থেকে শুরু করে রিমোট রিপোজিটরিতে কোড পুশ ও ট্র্যাক করা পর্যন্ত প্রতিটি ধাপ ক্রমানুসারে এবং সহজ বাংলা বিবরণে নিচে দেওয়া হলো:

---

### ১. লোকাল রিপোজিটরি শুরু করা (Initialize Git)
```bash
git init
```
* **বিবরণ:** একটি নতুন খালি লোকাল গিট রিপোজিটরি (Repository) তৈরি বা শুরু করার জন্য।

---

### ২. গিট ব্যবহারকারী সেটআপ করা (Configure User Info)
```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```
* **বিবরণ:** গিট কমিটের জন্য আপনার নাম এবং ইমেইল ঠিকানা সেট করার জন্য।

---

### ৩. সক্রিয় গিট অ্যাকাউন্ট/কনফিগারেশন দেখা (Check Active Account Config)
```bash
git config --list
```
* **বিবরণ:** বর্তমানে গিট কনফিগারেশনে কোন ইউজার ও ইমেইল সক্রিয় আছে তা দেখার জন্য।

---

### ৪. ফাইলের বর্তমান অবস্থা যাচাই করা (Check Status)
```bash
git status
```
* **বিবরণ:** কোন কোন ফাইল পরিবর্তন করা হয়েছে, ট্র্যাক করা হয়নি বা স্টেজিং এরিয়ায় আছে তা জানার জন্য।

---

### ৫. ফাইল স্টেজিং এরিয়াতে যুক্ত করা (Stage Files)
```bash
git add .
```
* **বিবরণ:** লোকাল ডিরেক্টরির সকল নতুন এবং পরিবর্তিত ফাইল কমিট করার জন্য স্টেজিং এরিয়াতে যুক্ত করার জন্য।

---

### ৬. পরিবর্তনগুলো কমিট (সংরক্ষণ) করা (Commit Changes)
```bash
git commit -m "আপনার বার্তা বা মেসেজ"
```
* **বিবরণ:** স্টেজিং এরিয়াতে থাকা ফাইলগুলোর পরিবর্তনকে একটি নির্দিষ্ট বিবরণ বা মেসেজসহ লোকাল ডাটাবেজে স্থায়ীভাবে সংরক্ষণ করার জন্য।

---

### ৭. ব্রাঞ্চের তালিকা দেখা (View Branches)
```bash
git branch
```
* **বিবরণ:** লোকাল রিপোজিটরিতে থাকা সব ব্রাঞ্চের তালিকা দেখতে এবং বর্তমানে আপনি কোন ব্রাঞ্চে কাজ করছেন তা চিহ্নিত করার জন্য।

---

### ৮. নতুন ব্রাঞ্চ তৈরি এবং পরিবর্তন করা (Create & Switch Branch)
```bash
git checkout -b <branch-name>
# অথবা আধুনিক গিট ভার্সনে:
git switch -c <branch-name>
```
* **বিবরণ:** নতুন একটি ব্রাঞ্চ তৈরি করে সরাসরি সেই ব্রাঞ্চে কাজ করার জন্য চলে যাওয়া।

---

### ৯. রিমোট রিপোজিটরি যুক্ত করা (Add Remote Repository)
```bash
git remote add origin <repository-url>
```
* **বিবরণ:** লোকাল রিপোজিটরির সাথে গিটহাব (GitHub) বা অন্য কোনো দূরবর্তী অনলাইন রিপোজিটরি কানেক্ট করার জন্য।

---

### ১০. রিমোট কানেকশন যাচাই করা (Verify Remote URL)
```bash
git remote -v
```
* **বিবরণ:** লোকাল রিপোজিটরির সাথে কোন রিমোট রিপোজিটরির ইউআরএল যুক্ত আছে তা দেখার জন্য।

---

### ১১. প্রথমবার রিমোট ব্রাঞ্চে পুশ ও আপস্ট্রিম সেট করা (Push & Set Upstream)
```bash
git push -u origin <branch-name>
```
* **বিবরণ:** লোকাল ব্রাঞ্চের কোড রিমোট রিপোজিটরিতে পাঠানো এবং ভবিষ্যৎ পুশ/পুলের ট্র্যাকিং সহজ করতে আপস্ট্রিম (-u) সেট করা।

---

### 1২. পরবর্তীতে কোড পুশ করা (Subsequent Pushes)
```bash
git push
```
* **বিবরণ:** আপস্ট্রিম সেট করার পর পরবর্তীতে লোকাল ব্রাঞ্চের যেকোনো নতুন পরিবর্তন সরাসরি রিমোট ব্রাঞ্চে পাঠানোর জন্য।
